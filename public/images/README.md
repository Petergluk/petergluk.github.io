# Изображения

Положите сюда фотографии — они станут доступны по адресу `/images/имя-файла.jpg`.

## Ожидаемые файлы

| Файл | Где используется | Рекомендуемый размер |
| :--- | :--- | :--- |
| `portrait.jpg` | Портрет на главной (hero) | 800×1000 px, вертикальный |
| `sessions.jpg` | Обложка карточки «Индивидуальная работа» | 800×500 px, горизонтальный |
| `classes.jpg` | Обложка карточки «Классы и семинары» | 800×500 px, горизонтальный |

## Как подключить

После того как положите файл, раскомментируйте соответствующую строку в коде.

**Портрет** — в `src/pages/index.astro`:
```html
<img src="/images/portrait.jpg" alt="Пётр Глухов" />
```

**Обложки карточек** — там же, внутри `<div class="card-cover">`:
```html
<img src="/images/sessions.jpg" alt="" />
```

Пока фото нет, на этих местах показываются тёплые градиентные заглушки — сайт выглядит целостно и без них.

## Фото в статьях

В markdown-файлах статей (`src/pages/texts/*.md`) достаточно обычной разметки:
```markdown
![Описание фото](/images/my-photo.jpg)
```
Стили для картинок в тексте уже настроены (скругление, отступы, ширина по контейнеру).
